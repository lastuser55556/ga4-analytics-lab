## Учебная публикация

Хотите чек-лист «Как начать изучать backend»? Напишите **ГАЙД** в комментариях — получите ссылку в Direct.

## Настройка ManyChat

| Поле | Значение |
|---|---|
| Keyword | ГАЙД |
| Public Reply | Проверьте Direct — там будет ссылка на материал. |
| Private Reply | Привет! Вот чек-лист «Как начать изучать backend». Нажмите «Получить материал», чтобы открыть его на сайте. |
| Кнопка | Получить материал → Open Website |
| URL | `https://ga4-analytics-lab.vercel.app/guide.html?utm_source=instagram&utm_medium=social&utm_campaign=backend_guide&utm_content=reel01` |

Open Website не создаёт новую DM-ветку: базовый сценарий заканчивается отправкой одной ссылки, а переход на сайт совершает пользователь.
